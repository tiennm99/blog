# Hugo Blog - Vietnamese Tech Content

Theme: hugo-theme-stack | Language: Vietnamese | Timezone: Asia/Ho_Chi_Minh (UTC+7)

## Commands

```bash
hugo server -D              # Start dev server at localhost:1313
hugo server -D -F           # Include future-dated content
hugo server --disableFastRender  # Full re-render on changes
```

## Content Structure

```
content/post/YYYY/MM/DD/index.md
```

## Skills

- **miti-add-post**: Process URLs, extract content, generate Vietnamese summaries, create/update daily newsletter posts
