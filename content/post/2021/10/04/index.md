Around July 2020, like most third-year university students, I went looking for my graduation internship. With a bit of luck, I got accepted into the VNG Tech Fresher (VTF) 2020 program at [VNG](https://www.vng.com.vn/).

I got to work in a field I had never explored before: game development. Then, lucky once again, I became a full-time employee, where I've been ever since. Perhaps I'll write a more detailed post to share that story later.

Since then, I've been exploring many new things I never knew about before, and studying Java and JavaScript more seriously. At one point, I learned a few cool things and wanted to blog about them, but when I updated the Coder theme to the latest version, it broke. Plus, I was lazy, so I stopped blogging altogether from that point on.

After neglecting the blog for more than a year, seeing this post means I've officially made a 'comeback' ^^.

I decided to move my blog to GitHub Pages at the new address: https://tiennm99.github.io

Along with that, I also updated the Coder theme to the current latest version. Moving forward, I'll try to write blog posts more regularly.

Thank you all!
